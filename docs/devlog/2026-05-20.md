## 대기열 구현 설계 정리

```
수강 신청 흐름 (enroll):
  강의 OPEN 확인 → 중복 체크(PENDING+CONFIRMED+WAITLISTED) → 사용자 역할 체크
  → 정원 확인(PENDING+CONFIRMED만 카운트)
    ├─ 자리 있음 → PENDING 저장
    └─ 만석     → WAITLISTED 저장

취소 흐름 (cancel):
  취소 처리 → 취소 전 상태가 PENDING/CONFIRMED였다면
    → 해당 강의의 WAITLISTED 중 가장 오래된 한 명을 PENDING으로 승격
```
